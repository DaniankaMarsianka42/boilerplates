# Создание сервисов

### Ход работы

### Создание inventory service:
1. Создали структуру Parts и мапу map[string]Value (в директории Inventory)
2. Создали proto file для генерации кода (в директории shared)
3. Внесли изменения в Taskfile(связанные с генерацией кода и линтинга для протофайла)
4. Создали buf.gen.yaml для описания плагинов
5. Создали buf.yaml, чтобы указать используемые и неиспользуемые линты
6. Создали buf.work.yaml и внесли туда первую директорию, в которой есть протофайл
7. Сгенерировали гошные файлы(чудом нах(в ручную, без таск файла))
8. Дальше реалезовали логику наших ручек и всо (в директории Inventory)

### Создание Payment service:
1. Все аналогично с inventory service, но по скольку все yaml файлы созданы то нам нужно только написать proto file
2. Заного сгенерировали гошные файлы тем же способом
3. Реалезовали логику наших ручек (в директории Payment)

### Создание Order service:
1. Создали декларотивное описание наших ручек в папке api (в директории Shared)
2. С помощью redocly забандлили все в один yaml файл
3. Исходя из нового файла сгенерировали в гошные файлы
